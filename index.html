Welcome! This is an interactive simulator of a Drosophila brain neural network using the Leaky Integrate-and-Fire model.

About This Simulator

This is a web-based simulation of a Drosophila melanogaster brain neural network based on:

  • Model: Leaky Integrate-and-Fire (LIF) neurons
  • Data: Janelia FlyEM male-CNS connectome
  • Features: Synaptic plasticity, multiple neurotransmitters
  • References: Nature 2024, PMC10187186

Membrane Dynamics:
C_m * dV/dt = g_leak * (E_leak - V) + I_syn + I_ext
